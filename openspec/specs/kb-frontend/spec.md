# kb-frontend 规范

## 目的
待定 - 由归档变更 knowledge-base 创建。归档后请更新目的。
## 需求
### 需求:概览面板
前端必须在知识库管理页面显示概览统计面板，包含总条目数、已索引数、覆盖率百分比和按源分布图表。

#### 场景:加载概览
- **当** 用户打开知识库管理页面
- **那么** 调用 GET /api/kb/stats，显示统计卡片和按源分布表格

### 需求:语义搜索界面
前端必须提供语义搜索功能，用户输入查询文本后展示向量相似度排序的结果列表。

#### 场景:执行搜索
- **当** 用户在搜索框输入 "AI手机" 并点击搜索
- **那么** 调用 POST /api/kb/search，展示结果列表（标题、来源、摘要摘录、相似度分数）

#### 场景:无结果
- **当** 搜索未匹配任何内容
- **那么** 显示"未找到相关内容"提示

### 需求:构建操作界面
前端必须提供"增量更新"和"全量重建"两个操作按钮，点击后触发后台任务并显示进度。

#### 场景:触发增量更新
- **当** 用户点击"增量更新"按钮
- **那么** 调用 POST /api/kb/tasks {"type": "incremental"}，显示进度条，每 2 秒轮询 GET /api/kb/tasks/{id}

#### 场景:触发全量重建
- **当** 用户点击"全量重建"按钮
- **那么** 弹出确认对话框，确认后调用 POST /api/kb/tasks {"type": "full_rebuild"}

#### 场景:进度显示
- **当** 后台任务运行中
- **那么** 显示进度条（progress/total）和百分比，任务完成后刷新概览统计

#### 场景:任务冲突
- **当** 已有任务运行中再次点击操作按钮
- **那么** 显示提示"已有任务正在运行，请等待完成"

### 需求:路由和导航
前端必须注册 /knowledge-base 路由，在导航栏添加"知识库"按钮。

#### 场景:导航访问
- **当** 用户点击导航栏"知识库"按钮
- **那么** 跳转到知识库管理页面
