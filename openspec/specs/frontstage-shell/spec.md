## 需求
### 需求:前台阅读壳
系统必须为内容消费型页面提供独立的前台阅读壳，并与后台工具壳在布局责任上明确分离。

#### 场景:前台页面使用阅读壳
- **当** 路由被标记为前台页面
- **那么** 系统必须渲染前台阅读壳，而不是后台工具壳或旧的统一布局

#### 场景:前台壳与业务页面解耦
- **当** 新增一个前台内容页面
- **那么** 系统必须允许仅通过布局元信息接入前台壳，而不要求在页面组件内重复实现公共头部和背景结构

### 需求:聚焦导航与品牌表达
前台阅读壳必须提供聚焦的导航层级和统一的品牌表达，禁止直接暴露全部后台管理入口。

#### 场景:前台导航收敛
- **当** 用户进入首页、搜索、历史、分享页或简报阅读态
- **那么** 页面必须仅展示与内容消费相关的导航入口和品牌元素

#### 场景:后台入口不干扰阅读
- **当** 用户处于前台阅读壳中
- **那么** 系统必须禁止将日志、设置、源管理等后台工具入口作为同层级主导航直接展示

### 需求:前台壳响应式行为
前台阅读壳必须适配桌面端与移动端，并在窄屏条件下保持阅读入口可访问和内容层级清晰。

#### 场景:桌面端展示完整头部
- **当** 浏览器处于桌面宽度
- **那么** 前台阅读壳必须展示完整品牌头部、频道或导航入口以及内容容器留白

#### 场景:移动端折叠导航
- **当** 浏览器处于移动端或窄屏宽度
- **那么** 前台阅读壳必须折叠非关键导航，并优先保证标题、内容列表和主操作入口可用
