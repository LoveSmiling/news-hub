## 需求
### 需求:关键词全文搜索
系统必须支持用户通过关键词搜索历史热榜条目的标题，返回匹配结果并按相关度和时间排序。

#### 场景:搜索热榜标题
- **当** 用户输入关键词进行搜索
- **那么** 系统必须利用 PostgreSQL 全文搜索能力（tsvector/tsquery）在 `hot_items` 表的 `title` 字段中查找匹配条目，返回结果必须包含来源、标题、热度值和采集时间

#### 场景:无搜索结果
- **当** 用户输入的关键词在历史数据中无匹配
- **那么** 系统必须返回空列表和友好提示信息

### 需求:搜索结果过滤
用户必须能够在搜索结果中按来源和时间范围进一步过滤。

#### 场景:按来源过滤搜索结果
- **当** 用户搜索关键词并选择特定来源（如"只看知乎"）
- **那么** 系统必须仅返回来自该来源的匹配结果

#### 场景:按时间范围过滤
- **当** 用户搜索关键词并指定时间范围（如"最近 7 天"）
- **那么** 系统必须仅返回该时间范围内的匹配结果

### 需求:历史热榜快照浏览
系统必须支持用户查看指定日期某站点的热榜历史快照，实现数据溯源。

#### 场景:查看指定日期的热榜
- **当** 用户选择某个日期和某个数据源
- **那么** 系统必须展示该日期该来源记录的所有热榜条目，按采集时间段分组展示

#### 场景:日期选择范围
- **当** 用户打开历史浏览功能
- **那么** 系统必须提供日历选择器，可选范围为数据库中有记录的最早日期到当天
