## 需求
### 需求:分类偏好设置
系统必须允许用户设置感兴趣的分类，首页优先展示用户偏好分类下的内容。

#### 场景:设置偏好分类
- **当** 用户在设置中选择感兴趣的分类（如"科技"和"开发"）
- **那么** 系统必须将偏好保存到本地存储，首页优先展示这些分类的数据源卡片

### 需求:阅读历史记录
系统必须记录用户点击过的热榜条目，用于后续个性化推荐。

#### 场景:记录点击行为
- **当** 用户点击某条热榜条目
- **那么** 系统必须记录该条目的来源、标题、分类和点击时间

#### 场景:展示阅读历史
- **当** 用户访问"阅读历史"页面
- **那么** 系统必须按时间倒序展示用户点击过的所有条目

### 需求:基于 Embedding 的内容推荐
系统必须利用文本 Embedding 模型（bge-m3）计算热榜条目的向量表示，结合用户历史兴趣向量，推荐与用户兴趣相似的新条目。

#### 场景:生成推荐列表
- **当** 用户访问"推荐"模块
- **那么** 系统必须基于用户近期阅读历史的 Embedding 均值，通过 pgvector 查找与用户兴趣向量最相似的未读热榜条目，返回推荐列表

#### 场景:冷启动处理
- **当** 用户无阅读历史记录
- **那么** 系统必须基于用户设置的偏好分类推荐热门条目，而非 Embedding 推荐

### 需求:推荐模块前端展示
前端必须提供"为你推荐"模块，展示个性化推荐的热榜条目列表。

#### 场景:展示推荐内容
- **当** 用户访问首页或推荐页面
- **那么** 页面必须展示"为你推荐"模块，列出个性化推荐的条目，每条包含标题、来源、热度值和推荐理由（如"因为你关注了 AI 相关话题"）
