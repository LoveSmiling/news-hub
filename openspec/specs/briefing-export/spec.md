## 需求
### 需求:导出简报为 Markdown
系统必须允许用户将已完成的简报导出为 Markdown 文件，纯前端实现。

#### 场景:成功导出
- **当** 用户在简报详情 modal 中点击"导出 Markdown"按钮
- **那么** 浏览器下载一个 .md 文件，文件名格式为 "{简报标题}.md"，内容包含标题、元信息（生成时间、类型）、正文内容和引用来源列表

#### 场景:导出包含完整引用来源
- **当** 简报有关联的引用来源（items）
- **那么** 导出的 Markdown 文件末尾包含 "## 引用来源" 章节，每条来源格式为 "序号. [标题](URL) — 来源名"

#### 场景:文件名特殊字符处理
- **当** 简报标题包含文件系统不允许的字符（如 / \ : * ? " < > |）
- **那么** 系统必须将这些字符替换为下划线或移除，确保文件名有效

#### 场景:未完成简报不可导出
- **当** 用户查看状态为 pending/generating/failed 的简报详情
- **那么** 导出按钮必须禁用或不显示
