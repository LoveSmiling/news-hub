## 新增需求

### 需求:话题热度曲线
系统必须追踪同一话题在不同时间点的热度变化，生成热度随时间变化的趋势曲线。

#### 场景:展示话题热度曲线
- **当** 用户选择某个话题或关键词
- **那么** 系统必须展示该话题在过去 N 天内的热度变化折线图，X 轴为时间，Y 轴为热度值

### 需求:跨平台话题聚合
系统必须识别不同平台上讨论同一事件/话题的热榜条目，将它们聚合在一起展示。

#### 场景:同一事件跨平台聚合
- **当** 多个平台的热榜中出现讨论同一事件的条目（如通过关键词重叠或 Embedding 相似度判断）
- **那么** 系统必须将这些条目聚合为一个话题组，展示各平台的讨论情况和热度对比

#### 场景:话题传播路径
- **当** 某话题在多个平台出现
- **那么** 系统必须记录该话题首次出现的平台和时间，以及后续扩散到其他平台的时间线

### 需求:热点爆发检测
系统必须检测热度急剧上升的话题，标记为"爆发中"并在前端醒目展示。

#### 场景:检测热度爆发
- **当** 某话题的热度在短时间内（如 1 小时）显著上升，或同时出现在 3 个及以上平台
- **那么** 系统必须将该话题标记为"爆发中"，在前端以醒目标识展示

### 需求:趋势可视化面板
前端必须提供趋势分析专属页面，展示热度曲线图、跨平台对比图和爆发话题列表。

#### 场景:访问趋势分析页
- **当** 用户导航到趋势分析页面
- **那么** 页面必须展示当前爆发话题列表、近期热度曲线图（ECharts）和跨平台热度对比图
