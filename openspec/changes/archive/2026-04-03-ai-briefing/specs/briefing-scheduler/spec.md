## 新增需求

### 需求:每日定时简报任务
系统必须在 APScheduler 中注册一个定时任务，每天 23:00 自动生成当日简报。

#### 场景:定时触发
- **当** 服务器时间到达 23:00 时
- **那么** 必须自动为每个活跃来源生成一份当日简报，并生成一份跨来源汇总简报

#### 场景:串行执行
- **当** 执行每日简报任务时
- **那么** 必须串行生成每份简报（一份完成后再开始下一份），避免同时打满 LLM 服务

#### 场景:部分失败
- **当** 某个来源的简报生成失败时
- **那么** 必须记录错误日志并继续生成剩余来源的简报，禁止因单个来源失败导致整个任务中断
