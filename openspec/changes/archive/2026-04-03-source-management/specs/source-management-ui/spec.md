## ADDED Requirements

### 需求:源管理页面表格
系统必须提供一个源管理页面（路由 `/sources`），包含数据表格展示所有源。表格列必须包含：勾选框、名称(display_name)、类型(type)、分类(category)、采集频率(schedule 的人类可读形式)、状态(status)、最近采集时间(last_collected_at)、操作按钮。

#### 场景:页面加载展示源列表
- **当** 用户导航到 `/sources` 页面
- **那么** 页面必须从 `GET /api/sources` 加载并展示所有源的表格

#### 场景:状态标签颜色
- **当** 源的 status 为 `active` 时显示绿色标签，`pending` 显示橙色标签，`disabled` 显示灰色标签，`error` 显示红色标签

### 需求:源列表筛选
页面必须提供筛选栏，支持按分类、类型、状态筛选源列表。

#### 场景:按分类筛选
- **当** 用户在分类下拉框选择 "科技"
- **那么** 表格必须只显示 category 为 "科技" 的源

#### 场景:按状态筛选
- **当** 用户在状态下拉框选择 "active"
- **那么** 表格必须只显示 status 为 "active" 的源

#### 场景:多条件组合筛选
- **当** 用户同时选择分类 "科技" 和状态 "active"
- **那么** 表格必须只显示同时满足两个条件的源

### 需求:新增源对话框
页面必须提供新增源的对话框，包含以下表单字段：name（唯一标识）、display_name（显示名称）、type（RSSHub/RSS 选择）、route（RSSHub 模式时必填）、url（外部 RSS 模式时必填）、category（可创建的下拉选择框，预置新闻/科技/娱乐/综合）、schedule（cron 表达式）、max_items（最大条数）。

#### 场景:选择 RSSHub 类型
- **当** 用户在 type 选择 "rsshub"
- **那么** 对话框必须显示 route 输入框，隐藏 url 输入框

#### 场景:选择 RSS 类型
- **当** 用户在 type 选择 "rss"
- **那么** 对话框必须显示 url 输入框，隐藏 route 输入框

#### 场景:自定义分类输入
- **当** 用户在 category 下拉框中输入一个新的分类名（如 "金融"）
- **那么** 系统必须允许使用该自定义分类，不限制为预设值

#### 场景:保存新增源
- **当** 用户填写完表单并点击保存
- **那么** 系统必须调用 `POST /api/sources` 创建源，成功后关闭对话框并刷新表格

### 需求:编辑源对话框
页面必须支持编辑现有源，点击操作列的编辑按钮打开对话框，预填当前配置。

#### 场景:打开编辑对话框
- **当** 用户点击某源的编辑按钮
- **那么** 对话框必须打开并预填该源的所有当前配置

#### 场景:保存编辑
- **当** 用户修改配置并点击保存
- **那么** 系统必须调用 `PUT /api/sources/{id}` 更新源，成功后关闭对话框并刷新表格

### 需求:删除源操作
页面必须支持删除源，点击操作列或批量操作触发。

#### 场景:删除确认
- **当** 用户点击删除按钮
- **那么** 系统必须弹出确认对话框，说明该操作会禁用源（不删除历史数据）

### 需求:预览测试功能
新增/编辑对话框必须包含 "预览测试" 按钮，点击后调用 `POST /api/sources/test` 并在对话框内展示抓取结果。

#### 场景:预览成功
- **当** 用户点击预览按钮且抓取成功
- **那么** 对话框内必须展示抓取到的条目列表（标题+链接）、条目总数和耗时

#### 场景:预览失败
- **当** 用户点击预览按钮且抓取失败
- **那么** 对话框内必须展示错误信息

### 需求:立即采集按钮
表格操作列必须包含 "立即采集" 按钮，点击后调用 `POST /api/sources/{id}/collect`。

#### 场景:立即采集成功
- **当** 用户点击立即采集按钮且采集成功
- **那么** 系统必须显示成功提示并刷新该源的 last_collected_at

### 需求:批量操作栏
页面必须在选中一个或多个源后显示批量操作栏，包含：批量启用、批量禁用、批量修改分类、批量立即采集按钮。

#### 场景:显示批量操作栏
- **当** 用户勾选至少一个源
- **那么** 页面必须显示批量操作栏，展示已选数量和操作按钮

#### 场景:隐藏批量操作栏
- **当** 用户取消所有勾选
- **那么** 页面必须隐藏批量操作栏

#### 场景:批量修改分类
- **当** 用户选中多个源并点击 "修改分类"
- **那么** 系统必须弹出分类选择对话框，确认后调用 batch API 更新分类

### 需求:BriefingsView 动态 sourceOptions
BriefingsView 的 sourceOptions 必须从 `GET /api/sources` 动态获取，禁止硬编码。

#### 场景:动态加载源选项
- **当** 用户打开 BriefingsView 页面
- **那么** sourceOptions 必须从 API 动态获取所有非 disabled 的源，构建为 `{ label, value }` 数组

### 需求:导航菜单
系统必须在侧边栏导航添加 "源管理" 菜单项，链接到 `/sources` 页面。

#### 场景:导航到源管理
- **当** 用户点击侧边栏 "源管理" 菜单项
- **那么** 系统必须导航到 `/sources` 页面
