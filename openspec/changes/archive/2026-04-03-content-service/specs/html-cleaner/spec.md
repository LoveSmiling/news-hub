## 新增需求

### 需求:清洗HTML为纯文本
系统必须提供 `clean_html(html: str) -> str` 函数，将 HTML 内容转换为干净的纯文本。

#### 场景:清洗基本HTML标签
- **当** 输入包含 `<p>`, `<div>`, `<span>`, `<br>`, `<h1>`-`<h6>` 等常见标签
- **那么** 必须移除所有标签，保留标签内的文本内容，段落之间以换行符分隔

#### 场景:清洗链接标签
- **当** 输入包含 `<a href="...">链接文字</a>`
- **那么** 必须保留链接文字，移除 `<a>` 标签和 href 属性

#### 场景:清洗媒体标签
- **当** 输入包含 `<img alt="描述">`、`<video>` 等媒体标签
- **那么** 必须保留 `<img>` 的 alt 文本（如有），移除其余媒体标签

#### 场景:清洗脚本和样式
- **当** 输入包含 `<script>...</script>` 或 `<style>...</style>` 块
- **那么** 必须完整移除标签及其内部内容，不保留任何文本

#### 场景:处理HTML实体
- **当** 输入包含 `&amp;`, `&lt;`, `&gt;`, `&nbsp;`, `&#13;` 等 HTML 实体
- **那么** 必须将实体转换为对应的字符（`&`, `<`, `>`, 空格等）

#### 场景:清理多余空白
- **当** 清洗后的文本包含连续多个空行或多余空格
- **那么** 必须压缩为最多两个连续换行，行内多余空格压缩为单个空格，首尾去除空白

#### 场景:处理空输入
- **当** 输入为 `None`、空字符串或纯空白字符串
- **那么** 必须返回空字符串 `""`

#### 场景:处理纯文本输入
- **当** 输入不包含任何 HTML 标签（已经是纯文本）
- **那么** 必须原样返回（仅做空白清理）

### 需求:截断长文本
系统必须提供 `truncate_text(text: str, max_chars: int = 2000) -> str` 函数，将超长文本截断到指定长度。

#### 场景:文本未超长
- **当** 文本长度 ≤ `max_chars`
- **那么** 必须返回原文本，不做修改

#### 场景:文本超长在句子边界截断
- **当** 文本长度 > `max_chars` 且在 `max_chars` 范围内存在句末标点（。！？；\n）
- **那么** 必须在最后一个句末标点处截断，并追加 `...` 表示有省略

#### 场景:文本超长无句子边界
- **当** 文本长度 > `max_chars` 且在 `max_chars` 范围内不存在句末标点
- **那么** 必须在 `max_chars` 处硬截断，并追加 `...`
