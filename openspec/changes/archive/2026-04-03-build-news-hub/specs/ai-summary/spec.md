## 新增需求

### 需求:AI 热榜摘要生成
系统必须利用本地 Ollama 运行的 Qwen2.5 模型，对热榜条目生成简短的中文摘要，帮助用户快速了解话题内容。

#### 场景:批量生成热榜摘要
- **当** 系统完成一轮数据采集
- **那么** 系统必须对排名靠前的条目（如 Top 20）调用本地 LLM 生成简短摘要（50-100 字），并将摘要存入 `hot_items.summary` 字段

#### 场景:按需生成摘要
- **当** 用户点击某条尚未生成摘要的热榜条目的"生成摘要"按钮
- **那么** 系统必须实时调用 LLM 生成摘要并返回给前端展示

#### 场景:Ollama 服务不可用
- **当** Ollama 容器未启动或 GPU 不可用
- **那么** 系统必须正常运行所有非 AI 功能，摘要字段显示为空，禁止因 AI 服务不可用导致整体系统故障

### 需求:关键词自动提取
系统必须从热榜条目的标题中自动提取关键词标签，用于后续话题聚合和趋势分析。

#### 场景:提取关键词
- **当** 新的热榜条目入库
- **那么** 系统必须通过 LLM 或 NLP 工具从标题中提取 3-5 个关键词标签

### 需求:AI 后端统一接口
系统的 AI 调用必须通过兼容 OpenAI API 格式的统一接口，支持在本地 Ollama 和云端 API 之间通过配置切换，无需修改业务代码。

#### 场景:使用本地 Ollama
- **当** 配置指向本地 Ollama 地址（`http://ollama:11434/v1`）
- **那么** 系统必须通过该地址调用本地模型完成推理任务

#### 场景:切换为云端 API
- **当** 管理员将配置切换为云端 API 地址（如 DeepSeek API）
- **那么** 系统必须通过云端地址完成推理任务，业务代码无需任何修改
