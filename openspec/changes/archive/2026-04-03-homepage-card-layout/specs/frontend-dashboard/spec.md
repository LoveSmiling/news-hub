## MODIFIED Requirements

### 需求:热榜卡片式展示
前端必须以卡片网格布局展示各平台的热榜数据，每个平台对应一个独立的卡片，卡片内按排名列出热榜条目。所有卡片必须采用统一的固定高度（420px），内容超出可视区域时必须支持滚轮滚动浏览。滚动条必须在滚动时短暂浮现细条样式，停止滚动后自动隐藏。

#### 场景:首页加载展示
- **当** 用户访问首页
- **那么** 页面必须展示所有已配置数据源的热榜卡片，每张卡片显示来源名称、条目列表（标题+热度值）和最近更新时间，所有卡片高度统一为 420px

#### 场景:卡片内容滚动
- **当** 卡片内容超出 420px 固定高度的可视区域
- **那么** 用户必须能通过滚轮滚动浏览剩余内容，滚动时必须浮现细条滚动条提供位置暗示，停止滚动后滚动条必须自动隐藏

#### 场景:点击条目跳转
- **当** 用户点击某条热榜条目
- **那么** 系统必须在新标签页中打开该条目的原始链接

### 需求:响应式布局
前端必须适配不同屏幕尺寸，使用自适应网格布局（auto-fill），在宽屏自动展示更多列，在窄屏自动减少列数。内容容器最大宽度为 1520px。

#### 场景:宽屏多列展示
- **当** 浏览器窗口宽度大于 1200px 且内容容器宽度足够
- **那么** 页面必须自动以 3 列或更多列网格布局展示卡片，每列最小宽度 380px

#### 场景:中等屏幕两列展示
- **当** 浏览器窗口宽度在 768px 至 1200px 之间
- **那么** 页面必须以 2 列网格布局展示卡片

#### 场景:移动端适配
- **当** 浏览器窗口宽度小于 768px
- **那么** 页面必须以单列布局展示卡片，卡片宽度撑满屏幕
