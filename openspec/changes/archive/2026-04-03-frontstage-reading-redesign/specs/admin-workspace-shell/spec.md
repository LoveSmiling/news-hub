## 新增需求

### 需求:后台工具壳
系统必须为对话、设置、日志、知识库、源管理等操作型页面提供独立的后台工具壳，并保持效率优先的工作台特征。

#### 场景:后台页面使用工具壳
- **当** 路由被标记为后台页面
- **那么** 系统必须渲染后台工具壳，并提供稳定的导航、容器和操作区结构

#### 场景:后台壳保留操作效率
- **当** 用户在后台页面执行筛选、配置、触发任务或查看日志
- **那么** 系统必须优先保证控件可见性、信息密度和操作路径清晰，而不是以阅读氛围取代工具效率

### 需求:共享设计令牌对齐
后台工具壳必须与前台阅读壳共享同一套基础设计令牌，以确保全站品牌一致性。

#### 场景:基础视觉一致
- **当** 用户从前台页面切换到后台页面
- **那么** 系统必须保持基础色板、圆角、间距和状态反馈的一致性，同时允许后台页面保留更高的信息密度

### 需求:后台导航分组
后台工具壳必须按功能分组组织管理入口，禁止与前台阅读入口混合为同一层级主导航。

#### 场景:后台入口集中呈现
- **当** 用户进入后台工具壳
- **那么** 系统必须集中呈现对话、设置、日志、知识库、源管理等后台入口，并与前台阅读入口形成清晰边界
